# Marine Intelligence MVP

## Architecture
- **Backend**: FastAPI + LangGraph, handling WebSocket stream and deterministic safety risk checks.
- **Frontend**: Next.js 14 + React Leaflet, real-time map and chat updates.
- **Database**: Neon Serverless Postgres with PostGIS extension.
